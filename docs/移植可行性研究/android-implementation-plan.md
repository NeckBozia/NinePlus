# Android 版实施计划

## 已定方案

| 决策 | 结论 |
| --- | --- |
| Phase 1 推送 | **不做**。前台服务自己轮询驱动通知与岛 |
| 服务端 | 用社区适配器 [`wuchiawuchi/nineplus-ha-server`](https://github.com/wuchiawuchi/nineplus-ha-server) |
| 领域层抽取 | **做**，见 [domain-extraction-plan.md](./domain-extraction-plan.md) |
| 代码位置 | **同仓库**，与 `mini-ninebot/` 并列一个 `android/` |
| iOS 版 | **两端长期并行维护**，不上 Kotlin Multiplatform，改用共享测试夹具对齐 |
| 地图 | **高德地图**。底图 GCJ-02，现有坐标转换代码原样保留 |
| 本地 GPS/IMU 记录 | **做**，正常排期 |
| 本地记录跨端同步 | **不做**，两端各存各的 |
| 防截屏 | **与 iOS 一致**：`SurfaceView.setSecure(true)`，屏幕正常显示、截图与录屏为空 |
| minSdk | 33（Android 13） |
| 包名 | `com.nineplus.android`（可改） |
| 应用名 | NineBot+（与 iOS 一致） |
| 图标 | 复用仓库根目录 `appicon.PNG`，按自适应图标规格切前景/背景层 |

## Phase 0 · 地基（3 周）

连不上服务端、没有存储和权限，后面什么都做不了。

| | 内容 | 工时 | 风险 |
| --- | --- | --- | --- |
| 0.1 | 网络层：Retrofit + 宽松 JSON 取值（服务端类型不稳定，数字可能是字符串、布尔可能是 0/1） | 3 天 | 低 |
| 0.2 | 数据模型：Swift struct → Kotlin `@Serializable`，含多键名兼容（`wnumber`/`sn` 这类同时认 snake 和 camel） | 3 天 | 低 |
| 0.3 | 存储：DataStore（配置、登录态、快照）+ Room（行程、轨迹点） | 2 天 | 低 |
| 0.4 | ViewModel + StateFlow 骨架、依赖注入、主题与设计 token（8 组明暗色直接搬） | 2 天 | 低 |
| 0.5 | 登录与服务器配置 | 2 天 | 低 |
| 0.6 | 定位权限 + 前台服务骨架 + 国产 ROM 电池优化引导 | 3 天 | 中 |

0.6 放进地基是因为后面的本地记录、后台刷新、充电实时活动三项都要用同一套东西。对应的 iOS 改动（记录不再限于前台，锁屏继续）已完成，见 commit `0abd9c4`。

## Phase 4 · 轨迹（4 周，累计 15 周）

两个数据来源要分清：

| | 来源 | 需要手机开着吗 | 有什么 |
| --- | --- | --- | --- |
| 接口轨迹 | 九号云（车自己上报） | **不需要** | 坐标 + 速度 + 航向 |
| 本地记录 | 手机 GPS + 加速度计 | 需要（锁屏可继续） | 坐标 + 速度 + **加速度 G 值**，采样更密 |

客户端显示逻辑是本地记录优先，没有才回退接口轨迹。

| | 内容 | 工时 | 风险 | 说明 |
| --- | --- | --- | --- | --- |
| 4.1 | 接口轨迹回放 | 2 天 | 中 | 九号返回的 JSON 形状不固定（iOS 侧写了约 450 行兼容），需确认社区服务端透传原始返回 |
| 4.2 | GPS + IMU 本地采集与滤波 | **10 天** | **高** | 13 个阈值、低通滤波系数全照 iPhone 调的；Android `TYPE_LINEAR_ACCELERATION` 各厂商质量参差、采样率只是 hint，**必须真机骑行重调**，至少覆盖两个品牌 |
| 4.3 | 实时速度环形表 + G 值 | 3 天 | 低 | 骑行中当仪表盘看 |
| 4.4 | 本地记录列表、详情、轨迹回放 | 4 天 | 中 | 依赖 2.1 的地图 |
| 4.5 | GPX 导出 | 1 天 | 低 | 建议改成系统分享，比 iOS 的剪贴板体验好 |

## Phase 5 · 设置与系统集成（4.9 周，累计 20 周）

| | 内容 | 工时 | 风险 | 说明 |
| --- | --- | --- | --- | --- |
| 5.1 | 诊断中心 | 3 天 | 低 | 刷新事件、缓存占用、原始返回值复制 |
| 5.2 | 防截屏（与 iOS 一致） | 3.5 天 | 中 | `SurfaceView.setSecure(true)`。屏幕正常显示、截图与录屏为空。**必须在附加到 window 前设置**，所以设置里切换开关需要重建 View 层级；Compose 侧要用 `AndroidView` 包装并自己处理圆角与 z-order |
| 5.3 | 桌面 Widget（Glance） | 7 天 | 中 | 三种尺寸 + 交互按钮；电量环、渐变进度条需变通 |
| 5.4 | 后台定时刷新 | 3 天 | 中 | 自适应间隔（充电 15 / 使用中 20 / 空闲 30 分钟）直接搬 |
| 5.5 | 充电实时活动 | **4 天** | 中 | 前台服务本地轮询驱动 + 标准 `Notification.ProgressStyle`（OPPO ColorOS 16 原生吃）。**小米超级岛已实测判定不可做，砍掉**（C1，见 [探针报告](./hyperos3-island-probe-report.md)）。注意 `canPostPromotedNotifications()` 默认 false，要做引导 |
| 5.6 | 应用快捷方式 | 1 天 | 低 | 长按图标的快捷入口 |

## 全程并行

| | 内容 | 工时 | 说明 |
| --- | --- | --- | --- |
| 图标资产 | **0 个定制**。内嵌 Material Symbols 可变字体 + 约 14 个 drawable 供 Widget／磁贴／地图 Marker 用 | 约 1–2 天，**不再是关键路径** | 97 个唯一 SF Symbol / 274 处引用，逐个比对 Material Symbols 官方清单后无一缺对应物（81 直接可用 + 16 近似可用）。原先「30–40 个定制、1 周设计、关键路径」的前提不成立，已撤。选可变字体是为了可变轴动画（充电时 FILL 渐变），代价是 Widget 侧另维护一套 drawable —— 已确认接受。详见 [icon-inventory.md](./icon-inventory.md) |
| 文案抽取 | 886 行中文进 `strings.xml` | 3 天 | 不能全局替换，有的中文是逻辑标识 |
