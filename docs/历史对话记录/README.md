# 历史对话记录

每次会话一个目录，**按 `日期-主题` 命名**。目录里放那次会话的原始记录，不做整理 —— 整理后的结论在 `docs/移植可行性研究/`。

## 每个会话目录里放什么

| 文件 | 内容 |
| --- | --- |
| `README.md` | 那次会话干了什么、有哪些子 agent、注意事项 |
| `main.jsonl` | 主对话的原始记录，一行一条 JSON |
| `subagents/agent-*.jsonl` | 每个子 agent 的完整过程 |
| `subagents/agent-*.meta.json` | 对应 agent 的任务描述 |
| `attachment-*.md` | 会话中上传的附件 |

## 为什么留原始文件

结论已经写在 `docs/移植可行性研究/` 里了，那些是给人看的。这里留的是**过程** —— 某个数字是怎么查出来的、某条结论推翻了什么、哪些路走过发现是死的。

新会话接手时先读 [`docs/当前状态.md`](../当前状态.md)，需要追溯某个判断的来由时再翻这里。

## 注意

这些是原始记录，包含绝对路径、内部 session ID、系统提示，以及会话中读过的全部文件内容。**仓库要公开的话，先决定这个目录留不留。**（已扫过，没有真实凭据。）
